# Create a handoff

## When ending a session

Update `handoffs/current.md` with the current date, files created or changed, checks performed and their outcomes, outstanding questions or permissions, known failures, and one concrete next task. Cross-check commands and detailed results against `docs/verification.md`; do not include credentials.

## When resuming

Before editing, read `README.md`, `AGENTS.md`, `docs/verification.md`, and `handoffs/current.md`; then verify the recorded state against the actual folder contents, dependency files, lockfiles, Git status, and the smallest relevant check. Correct stale handoff information before continuing.
