# Reviewed paper automation

Connect eligible analyst/reviewer decisions to the local paper simulator. Add Vue Start/Stop controls and an order size. For each newly completed candle after Start, claim the account/strategy/symbol/interval/candle once, freeze a fresh chart PNG, run the existing decision service, and submit only an eligible approved decision. Record analysis failures and vetoes as skips. Pending orders fill at the next eligible observed price, with cash, shares, decision age, automation generation, and idempotency rechecked in the existing SQLite fill transaction. Link the decision ID to the order, fill, and P&L row. Stop cancels pending automation and blocks late model replies. Keep manual chart questions advisory. Verify a duplicate approval, veto, Stop, and a browser fill against disposable test data.
